# 历法口径（calendar_core）

> 本文是钦天监**全库唯一的历法事实源**说明书。八字、紫微、奇门、六爻、择日全部调
> `scripts/calendar_core.py`，任何模块都不许自己推节气、自己算农历、自己换日。
> 引用状态词按契约 §8：`verified` / `pub` / `school` / `undated`。

---

## 1 · 何时用

**必须读本文（并调脚本）的场景**

| 触发场景 | 用哪条命令 |
|---|---|
| 生日在公历与农历之间换算（排盘第一步） | `calendar_core.py --date` / `--lunar` |
| 判断年柱是否已过立春、月柱是否已过节 | `ganzhi_year()` / `ganzhi_month()` |
| 出生在 23:00–23:59，要说明两派日柱 | `bazi.py --late-zi next_day\|same_day` |
| 出生时间在 1986–1991 年夏季 | `calendar_core.resolve_clock()`（自动还原夏令时） |
| 出生地与标准经线差得多（新疆、西藏、海外） | `--longitude` / `--place`（真太阳时） |
| 择日、问"今年流年"、紫微安命宫 | 都要先取本模块的农历月与节气 |

**两个入口等价**（模块可独立跑，也可走统一 CLI）：

```bash
python3 scripts/calendar_core.py --date 1990-05-15      # 单日：农历+干支+节气
python3 scripts/calendar_core.py --lunar 1990 4 21      # 农历反推公历（闰月加 --leap）
python3 scripts/calendar_core.py --year 2026            # 该年 24 节气时刻表
python3 scripts/xuan.py calendar --date 1990-05-15      # 同一实现，统一 CLI 分发
python3 scripts/bazi.py --solar 1990-05-15 --hour 12:00 --sex 男 --longitude 116.4
```

**模块依赖关系（谁调哪些函数，改动前必看）**

| 模块 | 依赖的 calendar_core 函数 | 依赖点 |
|---|---|---|
| `bazi.py` | `resolve_clock` / `true_solar_time` / `solar_to_lunar` / `ganzhi_year` / `ganzhi_month` / `ganzhi_day` / `ganzhi_hour` / `shichen_of` / `solar_terms` / `lunar_year_months` | 四柱、真太阳时、夏令时、大运起运折节、流年 |
| `ziwei.py` | `solar_to_lunar` / `lunar_to_solar` / `ganzhi_year` / `solar_terms` / `resolve_clock` | 农历生日、命宫身宫、五行局、四化 |
| `qimen.py` | `solar_terms` / `ganzhi_day` / `ganzhi_hour` / `prev_jieqi` / `next_jieqi` / `resolve_clock` | 时家奇门定时辰、节气定局与元 |
| `liuyao.py` | `ganzhi_day` / `ganzhi_month` / `solar_terms` | 日建月建、旬空、六神起例 |
| `fengshui.py` | `ganzhi_day` / `solar_terms` | 择日的建除十二神、黄道黑道 |

**不适用 / 不要用本文的场景**

- 公历 1850 年之前、2100 年之后：本内核直接拒绝（`DateError`），不许外推。
- 需要历史学家级别的古历复原（清初《时宪历》以前置闰争议）：本内核按现代天文回推，
  不作史学考证结论。
- 需要"哪一天最吉利"这类判断：本文只提供历法事实（干支、节气、建除），吉凶判词在
  `references/zeri.md`，不许在历法层夹带吉凶。

## 2 · 需要什么输入

| 字段 | 必填 | 缺了怎么办 | 产生的 warning.code |
|---|---|---|---|
| 公历日期（含年月日） | 是 | 无法排盘，`exit 2` + `BAD_DATE` | — |
| 出生时点 HH:MM | 否 | 时柱输出 `null`，只做六字分析 | `SHICHEN_UNKNOWN` + `LOW_CONFIDENCE` |
| 或时辰地支（子…亥） | 否 | 取该时辰中点时刻（子时取 00:00，即早子时） | 同上（不触发晚子时口径） |
| 性别 | 否 | `dayun.direction=null`，不排大运 | `SEX_REQUIRED` |
| 出生地经度 | 否 | 按标准经线 120°E 的钟表时排盘 | `LONGITUDE_ESTIMATED` |
| 是否闰月（农历输入时） | 否 | 默认非闰；该年无此闰月则 `BAD_DATE` | `LEAP_MONTH`（命中闰月时发） |
| 已故年份 | 否 | 流年按今年锚定推 10 年 | `DECEASED_LIUNIAN_CAP` |

**换算约定**：`--hour` 与 `--shichen` 互斥；`--solar` 与 `--lunar` 互斥。
`--place` 只用于查经度（内置 40 余个常用城市），查不到直接报错，不许猜。

**时区边界（保守口径）**：本内核的钟表时一律按**中国标准时 UTC+8** 解释。
海外出生（不在 UTC+8 时区）属于**降级场景**：必须由用户先把当地时间换算成 UTC+8
（或用 `--meridian` 指定当地标准经线并在结果里标 `LOW_CONFIDENCE`），否则时柱不可信。
不主动受理海外出生地查表，也不猜时区。

## 3 · 判定流程

排任何盘的第一步都是这七步，**每一步都以脚本输出为唯一事实源**：

1. **民用时 → 标准时**：`calendar_core.resolve_clock(dt, "fix")`
   → 夏令时区间内 −1 小时，返回的 warnings 里带 `CLOCK_CHANGE`。
   全库统一用 `"fix"`（准确性优先）；`"warn"` 只给"不改数据、只提示"的场景用。
2. **标准时 → 真太阳时**（仅在给了经度时）：`true_solar_time(dt, longitude, meridian)`
   → 返回 (真太阳时, 修正秒数)，修正 = 经度时差 + 均时差。产出发 `TST_APPLIED`。
   不给经度就**不修正**并发 `LONGITUDE_ESTIMATED`——绝不悄悄按 120°E 假装修正过。
3. **定农历**：`solar_to_lunar(y, m, d)` → `{year, month, day, leap, month_cn, day_cn,
   days_in_month, month_start, shuo, shuo_offset_minutes, shuo_near_midnight}`。
   `shuo_near_midnight=True` 时发 `SHUO_BOUNDARY`（见 §6 第 4 条）。
4. **定四柱**：`ganzhi_year()`（立春界）、`ganzhi_month()`（节界）、`ganzhi_day()`
   （子初 23:00 换日）、`ganzhi_hour(day_stem, h, m, late_zi)`（五鼠遁）。
5. **查临界**：出生时刻距交节 ≤120 分钟 → `JIEQI_BOUNDARY`，把"另一侧会得到哪一柱"
   写进消息；23:00–23:59 → `LATE_ZI`，把两派日柱都列出来。
6. **节气表**：`solar_terms(year)` 给 24 条（含 `datetime` 与 `jd`），择日/奇门/紫微
   的月令、局数、四化都从这里取，不许用农历月代替节气月。
7. **落地**：所有数字进 JSON 信封（契约 §3）；人类可读输出里的数字必须与 JSON 完全一致。

## 4 · 规则表

### 4.1 二十四节气与月柱对应（`pub`，见《淮南子·天文训》节气系统）

| 节（月柱起点） | 太阳视黄经 | 月支 | 中气 |
|---|---|---|---|
| 立春 | 315° | 寅 | 雨水 |
| 惊蛰 | 345° | 卯 | 春分 |
| 清明 | 15° | 辰 | 谷雨 |
| 立夏 | 45° | 巳 | 小满 |
| 芒种 | 75° | 午 | 夏至 |
| 小暑 | 105° | 未 | 大暑 |
| 立秋 | 135° | 申 | 处暑 |
| 白露 | 165° | 酉 | 秋分 |
| 寒露 | 195° | 戌 | 霜降 |
| 立冬 | 225° | 亥 | 小雪 |
| 大雪 | 255° | 子 | 冬至 |
| 小寒 | 285° | 丑 | 大寒 |

月干用**五虎遁**：甲己之年丙作首（寅月＝丙寅），乙庚之岁戊为头，丙辛必定寻庚起，
丁壬壬位顺行流，戊癸何方发，甲寅之上好追求。换算式：`月干 = (年干序×2 + 2 + n) mod 10`，
`n` 为自寅月起数的月序（寅=0）。

### 4.2 时柱：五鼠遁（`pub`）

| 日干 | 子时起干 | 口诀 |
|---|---|---|
| 甲、己 | 甲子 | 甲己还加甲 |
| 乙、庚 | 丙子 | 乙庚丙作初 |
| 丙、辛 | 戊子 | 丙辛从戊起 |
| 丁、壬 | 庚子 | 丁壬庚子居 |
| 戊、癸 | 壬子 | 戊癸何方发，壬子是真途 |

换算式：`时干 = (日干序 mod 5 × 2 + 时支序) mod 10`。时支：子 23:00–00:59、
丑 01:00–02:59……亥 21:00–22:59。

### 4.3 换日与换年（两处最易出错）

| 项目 | 口径 | 依据与备注 |
|---|---|---|
| 日柱换日 | **子初 23:00** 换日（默认 `late_zi="next_day"`） | `pub`：子时为一日之始；另有「夜子时算当日」的流派口径，用 `--late-zi same_day` 切换 |
| 年柱换年 | **立春交节时刻** | `pub`：命理以立春为岁首，不以正月初一 |
| 月柱换月 | **十二「节」交节时刻**（中气不换月） | `pub`：节气定月令 |
| 农历换年 | 正月初一 | 历法口径，与年柱无关（别混用！） |

**早晚子时的两派口径**（同一出生时刻，日柱可差一位）：

| 口径 | 23:00–23:59（晚子时） | 00:00–00:59（早子时） | 开关 |
|---|---|---|---|
| 子初换日（本库默认） | 用**次日**日柱，时干由次日日干起 | 当日日柱 | `--late-zi next_day` |
| 夜子时算当日（流派口径） | 用**当日**日柱，时干由当日日干起 | 当日日柱 | `--late-zi same_day` |

### 4.4 真太阳时

```
真太阳时 = 钟表时 + (经度 − 标准经线) × 240 秒/度 + 均时差
```
均时差在 ±16 分钟内变化（11 月初最大约 +16.4 分钟，2 月中旬最小约 −14.2 分钟）。
换算影响**两处**：① 时支/时柱；② 23:00 是否已过（换个日柱）。不改农历日期。
境外使用要把 `standard_meridian` 换成当地时区标准经线（如纽约 −75）。

### 4.5 中国夏令时（1986–1991，`verified`）

| 年份 | 起（02:00 → 03:00） | 止（02:00 拨回） |
|---|---|---|
| 1986 | 05-04 | 09-14 |
| 1987 | 04-12 | 09-13 |
| 1988 | 04-10 | 09-11 |
| 1989 | 04-16 | 09-17 |
| 1990 | 04-15 | 09-16 |
| 1991 | 04-14 | 09-15 |

区间内出生证/户口本上的钟表读数比标准时快 1 小时，**必须 −1 小时**再定时柱；
`resolve_clock()` 做完就发 `CLOCK_CHANGE`，消息里带"原值 → 修正值"。

### 4.6 农历置闰（`verified`，国标 GB/T 33661-2017 同款规则）

1. 月首＝含**朔**时刻（北京时 UTC+8）的那一日；
2. 含**冬至**之月为十一月；
3. 从一个十一月到下一个十一月之间若有 13 个月，则其中**第一个无中气**的月为闰月；
4. 闰月沿用上一个月的月号（如 2033 年闰十一月）。

已知特例：2033 年闰十一月、2020 年闰四月、2023 年闰二月、2025 年闰六月。

## 5 · 解读框架

历法层的输出只有"事实"，不给断语。**先报事实，再让上层模块解释**：

先说 → 公历/农历日期与生肖、四柱干支、节气位置（在哪个节之后、下一个节几分）
再说 → 真太阳时是否生效、夏令时是否还原、有无临界警告
最后 → 「这些是排盘事实，吉凶判断见 bazi.md / zeri.md」

**三种临界情形怎么说**（都必须把"另一侧"摊开，不许只报一个结果）：

| 情形 | 触发 | 说法的骨架 |
|---|---|---|
| 出生在交节前后 2 小时内 | `JIEQI_BOUNDARY` | "本盘按脚本的唯一定值取 X 月柱／年柱；离交节只有 N 分钟，若出生时刻记录有误，另一侧会是 Y。" |
| 出生在 23:00–23:59 | `LATE_ZI` | "夜（晚）子时两派并存：按子初换日为 A 日柱／B 时柱，按夜子时算当日为 C 日柱／D 时柱。本盘默认用前者，请确认用户所习流派。" |
| 出生在 1986–1991 夏令时区间 | `CLOCK_CHANGE` | "户口本/出生证上的钟表时是夏令时（+1h），已按 −1 小时还原为标准时 HH:MM 再定时柱；若不还原，时柱会变成 Z。" |

**不许做的事**：不得为了"看起来一致"而把两派的柱子平均、混搭，或只挑一个不说明。

### 好输出

> 公历 1990-05-15 11:00（本地钟表时 12:00，落在 1990 年夏令时区间，已 −1 小时还原）
> 农历 一九九〇年四月廿一（小月 29 天，朔 1990-04-25 12:27）
> 四柱：庚午 辛巳 庚辰 壬午；日主庚金，生于立夏后 9 天（下一节气芒种 06-06 06:46）
> 未给经度，按 120°E 钟表时排盘（若要真太阳时请给 `--longitude`）。
> 以上为排盘事实；十神格局与吉凶推断见 references/bazi.md。

### 坏输出

> ~~你生于庚午年辛巳月，夏天火旺，命里缺水，30 岁后走甲申运大发。~~
>
> 问题：① 没说钟表时被夏令时修正过；② 没给农历日期（无法与万年历对照）；
> ③ 把"火旺"直接接到断语，越过了层次；④ "30 岁"没写对应哪一步大运与起运日。

## 6 · 误判清单

| # | 常见错误 | 拦截办法 |
|---|---|---|
| 1 | **模型自己心算四柱**（"1990 年是庚午年"这类），边界日必错 | 一律调 `python3 scripts/bazi.py`；文档凡出现四柱必须附命令 |
| 2 | 用**农历正月初一**换年柱 | 年柱只认立春交节时刻；`ganzhi_year()` 已固化，别手写 |
| 3 | 拿**中气**换月柱（如用雨水换寅月） | 只有十二「节」换月；见 §4.1 表头 |
| 4 | 农历月首与官方历表差一天就以为内核坏了 | 先看 `shuo_offset_minutes`：|朔−子夜| ≤15 分钟时不同天文级数实现会差一天。本内核在 1914-11-18、1916-02-04、1920-11-11、2097-08-08、1863-01-20、1880-11-02、1896-02-13 这 7 个月首上与 lunar_python（寿星系）差一天，经 **JPL Horizons 与 USNO 月相 API 双源仲裁本实现为准**（真朔在零点后 1–5 分钟）。发 `SHUO_BOUNDARY` 就是提醒这条 |
| 5 | 忽略 1986–1991 夏令时，直接拿户口本钟点定时柱 | `resolve_clock()` + `CLOCK_CHANGE`；bazi/ziwei/qimen 必须同口径，否则同一人两个时辰 |
| 6 | 把 23:30 出生当"当天"了事 | 默认子初换日→次日日柱；`LATE_ZI` 消息里同时给两派结果，让用户选 |
| 7 | 新疆/西藏/海外出生不修正经度 | `--place`/`--longitude` 给真太阳时；缺经度时必须发 `LONGITUDE_ESTIMATED`，不许假装修正 |
| 8 | 2050 年后的节气时刻当成"定值"用来判临界 | ΔT 未来值物理不可预测，2050 年后节气时刻是"预报"；临界日必须发 `JIEQI_BOUNDARY` |

| 10 | VSOP87D 太阳黄经级数 | IMCCE 公开星表 VSOP87D（Bretagnon & Francou 1988） | `verified` | 节令时刻与 lunar_python 差 0–15 秒；与 JPL Horizons 视黄经一致 |
| 11 | 朔望级数 | Meeus《Astronomical Algorithms》第 49 章（含 14 项行星改正） | `verified` | 7 个争议朔与 JPL Horizons 差 +1…+3 秒（2097 年 −19 秒，ΔT 外推） |
| 12 | ΔT（TT−UT1） | IERS 实测序列（1850–2024）；2025 年后按潮汐减速二次外推 | `pub` | 与 lunar_python 在 1900–2024 差 ≤2 秒；未来差异见 docstring 第 4 条 |

**核对范围与结论**（`verified`）：1850-01-01–2100-12-31 共 91 672 天逐日与 lunar_python 1.4.9
比对，**年柱/月柱/日柱 0 处不一致**；农历日期 210 天不一致，全部集中在上述 7 个月首，
经 JPL Horizons 与 USNO 月相 API 双源仲裁**本实现正确**；节气时刻 5 973 条差 0–15 秒
（2050 年后因 ΔT 外推口径不同，可差到分钟量级，属不可消除的物理不确定性）。

**未验证**：1850 年以前、2100 年以后；2050 年后节气时刻的历史定值（无权威历表可对）；
真太阳时未计极移与地方性大气折射（影响 < 1 秒）。
