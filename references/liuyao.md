# 六爻纳甲（文王卦）方法论

> 体系：京房纳甲 → 火珠林 → 明清卜筮诸家（《卜筮正宗》《增删卜易》一系）。
> 唯一事实源：`python3 scripts/liuyao.py`。**纳甲、世应、六亲、六神、伏神一律以脚本输出为准，模型不得心算装卦。**
> 本文只写"怎么读"，不写"怎么算"——凡能算出数的，都调脚本。

---

## 1 · 何时用

**触发词**：六爻、摇卦、起卦、装卦、纳甲、世应、用神、文王卦、铜钱卦、蓍草、动爻、之卦。

**适用**（单一事项 + 明确时间窗 + 有成败可判）：

- 某件具体事的成败与时机：这单能不能签、这周能不能收到款、面试过不过。
- 对方态度与动向：他会不会回、对方底线在哪、有没有第三人介入。
- 失物/寻人/走失宠物的方位与能否找回。
- 诉讼、纠纷、谈判的强弱对比。
- 短期内的决策取舍（一事一占，三到六个月为常规窗口）。

**明确不适用**（遇到改路由，别硬占）：

- 一生的格局与长期趋势 → 走八字/紫微（`references/bazi.md`、`references/ziwei.md`）。
- 生死寿数、绝症诊断 → **不占**。六爻可问"病势缓急"，不可问"还能活多久"。
- 同一件事反复占 → 违反"初筮告，再三渎"（§6 第 4 条）。
- 复合问题（"我事业婚姻财运如何"）→ 必须拆成单问，一次一爻题。
- 需要精确到小时的应期 → 六爻分辨率是天/月，不是小时。

## 2 · 需要什么输入

| 字段 | 必填 | 缺了怎么办 | `warning.code` |
|---|---|---|---|
| `method` | 是 | 三选一：`coins`（三枚铜钱）／`yarrow`（蓍草）／`lines`（自报六爻） | — |
| `date` | 是 | 缺则用当天；**必须问清**，因为月建日辰全靠它 | `LOW_CONFIDENCE` |
| `hour` | 否 | 缺则不影响装卦（六爻不用时柱），但影响六神以外的时辰类神煞，缺则跳过 | — |
| `seed` | 模拟起卦必填 | 未给则随机生成并**落进输出顶层**；用户自报 `--lines` 时 seed 为 null | — |
| `ask` | 是 | 缺则无法取用神，**拒绝出结论**，只出卦体 | `LOW_CONFIDENCE` |
| 用户自摇结果 | 用 `--lines` 时必填 | 用户线下摇的六爻，自下而上 6 位，1 阳 0 阴，如 `--lines 101001`；动爻用 `--moving 2,4,5` 另标（1–6 自下而上） | — |

**取数的三条口径**：

1. 用户线下自己摇 → 用户报爻，脚本只装卦（`--lines`）。模型不替用户摇。
2. 用户要求在线起卦 → 脚本按所选方法抽随机数，`--seed N` 可回放。
3. 用户只记得"摇出个什么卦"但记不清动爻 → 按无动爻的静卦处理，并明确告知"缺动爻，只能看卦体与用神旺衰，不看变化"。

## 3 · 判定流程

按顺序走，每步的产物是下一步的输入。跳过任一步，后面的判断就是无源之水。

1. **过纪律闸门**：确认"一事一占"。把问题写成一句带时间窗的话（"未来 3 个月，这笔 12 万货款能否收回"）。写不出就退回 §1。
2. **起卦**：`python3 scripts/liuyao.py --coins --date 2026-11-18 --ask "<问题>" --seed 42 --json`。产出 `lines[6]`（`pos/yinyang/moving/kong/yuepo/chong_ri`）与 `xunkong`（旬空）。用户自摇则用 `--lines 101001 --moving 2,4,5`。
3. **定卦体**：读 `ben_gua.{name,trigrams,palace,palace_wuxing,generation,shi,ying}` 与 `bian_gua`。`palace` 是卦宫、`generation` 是第几世（本宫/一世…游魂/归魂）、`shi`/`ying` 是世应爻位（与 §4.2 世应表互校）。**宫五行决定六亲，不是本卦五行决定**。
4. **装纳甲**：读 `lines[].najia.{stem,branch}`。核对是否合 §4.3 表；不符则脚本有 bug，报回，不许手改。
5. **定六亲**：按 `palace` 五行与 `najia.branch` 五行，查 §4.4 表得每爻六亲。
6. **定六神**：按 `day_ganzhi` 的天干，查 §4.5 起法，自初爻顺布六神。
7. **查伏神**：本卦六亲不全时，读 `fushen[]`（`pos/liuqin/najia/feishen_liuqin/note`）。空数组即六亲俱全，不需伏神。
8. **取用神**：按 §2 的 `ask`，查 §4.6 表定用神。**用神只能有一个主用神**，其余为原神/忌神/仇神。
9. **判旺衰**：以 `month_ganzhi` 月建与 `day_ganzhi` 日辰，判用神旺相休囚死；查空亡、月破、日冲（§4.7）。
10. **看动变**：动爻 → 变爻，查进神/退神、反吟/伏吟、化空/化破（§4.8）。无动爻即静卦，断法不同。
11. **定应期**：按 §4.9 逐条对，给出时间窗与依据。给不出就写"无明确应期"，不许编。
12. **出报告**：按 §5 模板逐段填，末尾附 `method/date/seed/lines` 供回放。

> 第 2–7 步全部来自脚本 JSON；第 8–11 步全部来自 §4 的表。**任何一句结论都必须能指回"第 N 步 + 4.x 表"**，指不回去就是编的。

## 4 · 规则表

### 4.1 三种起卦法与随机性（必读）

| 方法 | 操作 | 老阳 | 少阴 | 少阳 | 老阴 | 说明 |
|---|---|---|---|---|---|---|
| 铜钱（以钱代蓍） | 三枚钱掷六次，每次记背数 | 1/8 | 3/8 | 3/8 | 1/8 | 通行法，快；明清以来主流 |
| 蓍草（大衍筮法） | 五十取一，三变成一爻，十八变成卦 | 3/16 | 7/16 | 5/16 | 1/16 | 《周易·系辞》本法；慢，仪式重 |
| 手摇（摇卦筒） | 三枚钱入筒摇，倒出记背 | 1/8 | 3/8 | 3/8 | 1/8 | 概率同铜钱；差别在手感与不可偷看 |

**两者不是等价物**：蓍草法老阳:老阴 = 3:1，铜钱法是 1:1。同一问题用不同法起，动爻的阴阳倾向就系统性不同。要严谨就固定一种法并在输出里写明。

**字／背的阴阳口径**：上表按主流用法——**背为阳面**，三背=老阳（重）、三字=老阴（交）、一背二字=少阳（单）、二背一字=少阴（拆）。另有"以字为阳"的一派（`school`），起出的卦会整体阴阳互换。所以：用户自摇时报的是"爻"还是"背数"必须问清；脚本 `method` 与用户口径不一致时，先对齐口径再装卦。

**随机性的诚实说明（硬要求）**：

- 脚本里的随机是 `random.Random(seed)` 伪随机，模拟的是**上述概率分布**，不是任何"感应"。seed 落顶层，可回放、可复核、可证伪。
- 文本环境无法复现物理抛掷。任何"我在线帮你摇了一卦"的说法，实质是"按概率生成了一组数"，输出里必须这么写。
- **不承诺准确率**。六爻是决策辅助与结构化提问工具，不是预测机。禁止写"卦象准确率 90%"这类话。
- 用户自摇的卦优先级最高：那是唯一带物理随机性的输入，脚本只负责装卦、不改变用户的爻。
- 同一 seed 必得同一卦，这是可复现性要求；不同 seed 得同卦是巧合，不许解读成"天意重复"。

### 4.4 六亲取法（以卦宫五行为"我"）

| 关系 | 六亲 | 例（宫为金） |
|---|---|---|
| 同我（比和） | 兄弟 | 金见金：申、酉 |
| 我生者 | 子孙 | 金生水：子、亥 |
| 我克者 | 妻财 | 金克木：寅、卯 |
| 克我者 | 官鬼 | 火克金：巳、午 |
| 生我者 | 父母 | 土生金：辰、戌、丑、未 |

**关键**：这里的"我"是**卦宫五行**（如"天风姤"属乾宫，我=金），不是本卦上下卦的五行。用错这一步，全卦六亲皆错。

### 4.5 六神起法（日干起青龙，自初爻顺布）

起法：按日干定初爻所值神，然后自下而上依序 `青龙 → 朱雀 → 勾陈 → 螣蛇 → 白虎 → 玄武` 循环。

| 日干 | 初爻起 |
|---|---|
| 甲、乙 | 青龙 |
| 丙、丁 | 朱雀 |
| 戊 | 勾陈 |
| 己 | 螣蛇 |
| 庚、辛 | 白虎 |
| 壬、癸 | 玄武 |

例：庚日占，初爻白虎、二爻玄武、三爻青龙、四爻朱雀、五爻勾陈、上爻螣蛇。

### 4.6 用神取法

| 所问 | 用神 | 备注 |
|---|---|---|
| 自身处境、我方 | 世爻 | 世爻为"我"，永远参与判断 |
| 对方、竞争者、同辈、合伙人 | 兄弟 | 也主破财、分夺 |
| 父母、长辈、师长、房宅、车、文书证件、合同、学历 | 父母 | 问房子看父母爻，不看财 |
| 子女、晚辈、下属、学生、宠物 | 子孙 | 子孙又为"福神"、医药、解忧 |
| 官职、功名、上司、官司、疾病、盗贼、丈夫（女占） | 官鬼 | 官鬼为"忧疑"，也主压制 |
| 财物、薪资、货款、股票、妻子（男占） | 妻财 | 妻财为"用财"，也主妻 |
| 事情本身 | 用神即所问之事；世爻为求测人 | 二者分看 |

**主用神只取一个**。取定后其余四亲的角色：生用神者=原神，克用神者=忌神，克原神者=仇神。
**取错用神是全流程最致命的错误**——问事业取妻财、问求财取官鬼，后面算得再准也是废卦（§6 第 2 条）。

### 4.7 月建、日辰与旺衰

| 项 | 规则 | 判读 |
|---|---|---|
| 月建 | 月令为提纲，主一旬之旺衰 | 用神临月建、得月建生 → 旺；被月建克 → 衰 |
| 日辰 | 日为一日之主，力大于月建 | 日辰生用神 → 有生机；日辰克用神 → 受制；日辰冲用神 → 动（旺则暗动，衰则日破） |
| 旺相休囚死 | 以月建五行为准：当令者旺、我生者相、生我者休、克我者囚、我克者死 | 用神旺相则事易成，休囚死则难 |
| 空亡 | 日辰旬空 | 旺相而空=待出空可用；休囚而空=真空无用 |
| 月破 | 与月建相冲之爻 | 月破得日辰生扶，为"破而不破"，仍可用 |
| 日破 | 衰弱之爻被日辰冲 | 破而无用；旺相被冲为暗动，反主事发 |

### 4.8 动变：进退、飞伏、反吟伏吟

| 象 | 判据 | 读法 |
|---|---|---|
| 进神 | 动爻化出同五行顺进之支：寅→卯、巳→午、申→酉、亥→子、辰→未、未→戌、戌→丑、丑→辰 | 力量递增，事向前推进 |
| 退神 | 反向化出：卯→寅、午→巳、酉→申、子→亥、未→辰、戌→未、丑→戌、辰→丑 | 力量递减，事向后缩 |
| 伏神 | 本卦缺某六亲，取本宫首卦该六亲之爻，伏于本卦同爻位下 | 伏神须"拔"：得日月生扶、飞神生伏、飞神空破可出；飞神克伏神则难出 |
| 飞神 | 伏神之上那一爻（明爻） | 飞生伏=得拔；伏生飞=泄气；飞克伏=压制 |
| 反吟 | 卦变相冲（乾↔坤、坎↔离、震↔巽、艮↔兑），或动爻化出相冲之支 | 主反复、来回折腾、事有翻覆 |
| 伏吟 | 卦体不变而爻动（内外卦同），或动爻化出同支 | 主停滞、拖延、原地不动、忧闷 |

### 4.9 应期判断

| 用神状态 | 应期取法 | 例 |
|---|---|---|
| 用神旺相安静（静卦） | 以用神地支值日，或以值月 | 用神寅木旺 → 寅日/寅月 |
| 用神发动 | 以动爻或变爻地支值日/值月 | 动化午 → 午日 |
| 用神空亡 | 出空之日（冲空或填实） | 旬空午 → 午日填实、子日冲空 |
| 用神月破 | 出月填实 | 月破酉 → 出酉月后再逢酉日 |
| 用神伏藏 | 伏神值日，或飞神被冲开之日 | 伏神巳 → 巳日；飞神亥 → 冲亥之巳日 |
| 用神逢合 | 冲开之日 | 用神与日辰合（子丑合）→ 未日冲开 |
| 用神逢冲 | 逢合之日 | 用神被冲 → 合之日应 |
| 忌神发动 | 忌神受制或入墓之日 | 忌神午火 → 子日制之 |

**远近分辨率**：近事以日断（一旬内）、中事以月断（一季内）、远事以年断。给不出上述任一依据时，输出"无明确应期"，不许凑一个日期。

> 上表八条为诸家通行的取法次序（`school`），不同流派在"先取动爻还是先取值日"上有分歧；本文取"先看用神状态，再取动变"一序，全流程不变。

## 5 · 解读框架

**顺序**：结论 → 卦体 → 用神状态 → 关键生克（≤3 条）→ 应期 → 不确定项 → 回放信息。

1. **结论先给，带条件**："这单能成，但要走两轮，钱到位在月底。"不说"大吉"。
2. **卦体一句话**：本卦/之卦、属哪宫、世在几爻、应是谁。给用户一个可核对的骨架。
3. **用神状态**：用神是哪一爻、什么六亲、旺衰如何、有没有空破。这是全卦的重心，必须写清。
4. **关键生克最多 3 条**：只说改变结论的那几条，不许把十二种关系全列一遍。
5. **应期给窗口 + 依据**："月底"要能追到 §4.9 某一行。
6. **不确定项必写**：缺时辰、缺动爻、用神两现、月建日辰临界——有什么写什么。

## 6 · 误判清单

| # | 常见错误 | 拦截办法 |
|---|---|---|
| 1 | **模型心算装卦**：自己推纳甲、自己排世应，结果错爻 | 纳甲/世应/六亲/六神/伏神五项必须逐项对上脚本 JSON；对不上就报 bug，不许手改 |
| 2 | **用神取错**：问事业取妻财、问求财取官鬼、问房子取财爻 | 用神只能从 §4.6 表取；取完把"问题→用神"写进输出，让用户能一眼看出取错 |
| 3 | **卦宫五行用错**：拿本卦上下卦五行当"我" | 六亲必须以 `ben_gua.palace` 的宫五行起；实例校验：天风姤属乾宫金，不是"天=金、风=木" |
| 4 | **一事多占/重复占**：结果不满意再摇一次 | 输出首行记录起卦时间与 seed；同一问题二次起卦时，先引第一次结论并说明"再占不采信" |
| 5 | **只看用神不看世应**：用神旺就断成，忽略世爻受克 | 世爻必须独立判一次：世受克 → 事成而人受损；世空 → 当事人未到位 |
| 6 | **忽略空亡月破**：把真空之爻当旺爻用 | 判旺衰后强制再查空亡、月破、日破三项，任一命中必须在输出里写出处置 |
| 7 | **动爻当爻看**：只看本卦不看之卦，或反过来只读之卦 | 动爻必须成对读：本卦该爻 → 变爻，看进退/反吟伏吟；静爻不得当动爻用 |
| 8 | **应期编日期**：没有 §4.9 依据也硬给日子 | 应期必须标注取自 §4.9 哪一行；标不出就写"无明确应期" |
| 9 | **起卦法混用不声明**：铜钱法与蓍草法概率不同却当同一回事 | `method` 必写进输出；不同法不得比较结果，也不得用一法的卦套另一法的断语 |
