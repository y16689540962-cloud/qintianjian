# 姻缘 · 合婚 / 夫妻宫 / 桃花 / 婚期

> 姻缘在术数里最容易被做成两件事：**生肖配对的民俗简化**，和**恐吓式的「你克夫/克妻」**。
> 本文的做法是：能算的（日支关系、夫妻星、夫妻宫、流年桃花）按规则算；算不了的（对方到底怎么想）直说算不了。

---

## 1 · 何时用

**用**：
- 「我和他合不合」「这段关系能不能走下去」「为什么总遇到同一类人」
- 「什么时候有姻缘 / 什么时候结婚合适」「婚期选哪天」
- 「我命里的桃花是什么类型」（偏自我认识，不涉第三人）

**不用**：
- 未经同意分析第三人的隐私盘（只谈双方相处模式；对方不知情时不排他的盘）
- 用合婚结论替代分手/结婚决定（`safety-ethics.md` 红线 9）
- 判断「他有没有出轨」——这是现实信息问题，不是命理问题

---

## 2 · 需要什么输入

| 情形 | 需要 | 缺了怎么办 |
|---|---|---|
| 看自己的姻缘 | 本人：生日 + 时辰 + 性别 + 城市 | 缺时辰 → 六字盘，只谈夫妻宫（日支）不谈时柱 |
| 双方合婚 | 两人各自上述信息 | 缺一方 → 只做「你的盘 + 你描述的相处模式」，不排对方盘，发 `LOW_CONFIDENCE` |
| 婚期 | 双方生日年 + 意向月份范围 | 缺生日 → 只能按通书宜忌粗筛，说明未合命主 |
| 求签解读 | 用户自己抽到的**签诗原文** + 签系（观音/关帝/月老/吕祖） | 用户没抽到 → 建议去实体庙或自抽，**AI 不代抽、不编签诗** |

同性伴侣：传统合婚的「男看财、女看官」不适用。改用**双方日支关系 + 用神互补 + 夫妻宫星曜**三项，并在文中说明
「这是对传统规则的现代调整（流派口径之外）」。

## 3 · 判定流程

### Step 1 · 各自排盘（不许省）

```bash
python3 scripts/bazi.py --solar 1990-05-15 --hour 12:00 --sex 男 --json
python3 scripts/ziwei.py --solar 1992-08-03 --hour 09:20 --sex 女 --json
```

两份 JSON 就是后续全部事实来源。缺时辰的那份会带 `SHICHEN_UNKNOWN`，此时**不碰时柱、子女宫**。

### Step 2 · 八字合婚四看

按顺序看，每看一条写一句结论 + 出处状态：

| # | 看什么 | 怎么判 | 权重 |
|---|---|---|---|
| 1 | **日支关系**（夫妻宫对夫妻宫） | 六合/三合 → 相处顺；六冲 → 节奏冲突；相刑/六害 → 摩擦点明确 | 高 |
| 2 | **日干关系**（你我本体） | 天干五合 → 相互吸引强；相生 → 一方付出多；相克 → 谁克谁、克在哪 | 高 |
| 3 | **夫妻星** | 男看财星、女看官星：有无、旺衰、是否被冲克 | 中 |
| 4 | **用神互补** | 一方喜用正是另一方多的五行 → 互补；双方都缺同一五行 → 共同短板 | 中 |
| 5 | 年命纳音 / 生肖 | 仅作**民俗层**参考，必须标 `undated`，不许拿「六冲生肖不能结婚」吓人 | 低（默认不说） |

**权重纪律**：1、2 条冲突时以「日支（夫妻宫）」为主，因为它代表共同生活的场域；日干代表个体吸引。
两者相反时标准写法：

> 「日干相生，初见投缘；日支相冲，长期同住容易在生活节奏上顶牛（如一个要热闹一个要清静）。
> 前者决定你们怎么开始，后者决定你们怎么过。」

### Step 3 · 紫微夫妻宫

看三个东西：

1. **夫妻宫主星**：主星性格与关系模式（表见 §4.4）。
2. **生年四化落夫妻宫**：化禄 → 关系中有资源/甜；化权 → 主导权争；化科 → 体面、外在评价好；化忌 → 执念、旧账。
3. **大限夫妻宫**：当前大限是否走到夫妻宫或其对宫，主这十年感情议题被放大。

八字与紫微都指向同一摩擦点时，可以写「两派同指」；**但要说清两派共享同一出生时间，不是双重验证**（`synthesis.md` §2）。

### Step 4 · 桃花与婚期

- **红鸾、天喜**：以年支查（§4.5），流年走到 → 婚恋议题活跃。
- **咸池（桃花）**：以年支三合局查（§4.6），主人的吸引力类型，不等于「会出轨」。
- **婚期窗口**：流年红鸾/天喜 + 大运夫妻宫 + 八字夫妻星被引动，三者有二即可谈「窗口」，不承诺「必成」。
- 明确写清窗口是**流年**还是**流月**，起止年月。

### Step 5 · 求签（只解读，不代抽）

用户自带签诗时：

1. 先问清**签系**（观音灵签 100 / 关帝灵签 100 / 月老灵签 / 吕祖灵签 / 妈祖签），签系不同，签诗与解读都不同。
2. 解读四步：**签诗意象 → 典故 → 吉凶等级 → 应期与行动**。
3. 用户给的签诗若与常见签系对不上，说明「可能记错或属其他签系」，按原文意象解读，不硬套签号。
4. **绝不生成签诗、绝不编签号**。AI 凭空写四句七言当「签文」是最恶劣的伪造。

### Step 6 · 婚期择日（要具体日子时）

转 `references/zeri.md`：先避月破/四离四绝/冲双方本命，再看嫁娶宜日；调用

```bash
python3 scripts/fengshui.py zeri --event 嫁娶 --start 2027-03-01 --end 2027-05-31 --birth-year 1990 --birth-year 1992
```

## 4 · 规则表

### 4.1 天干五合（`pub`，《渊海子平》）

| 合 | 化 | 关系含义 |
|---|---|---|
| 甲己 | 土 | 相吸且能成事，甲被己牵住 |
| 乙庚 | 金 | 柔对刚，契约型结合 |
| 丙辛 | 水 | 热烈遇收敛，需磨合 |
| 丁壬 | 木 | 暗合，默契型 |
| 戊癸 | 火 | 老少配式的互补 |

### 4.2 地支关系（`pub`）

| 类型 | 组合 |
|---|---|
| 六合 | 子丑、寅亥、卯戌、辰酉、巳申、午未 |
| 三合 | 申子辰（水）、亥卯未（木）、寅午戌（火）、巳酉丑（金） |
| 六冲 | 子午、丑未、寅申、卯酉、辰戌、巳亥 |
| 六害 | 子未、丑午、寅巳、卯辰、申亥、酉戌 |
| 相刑 | 子卯（无礼之刑）、寅巳申（恃势之刑）、丑戌未（无恩之刑）、辰午酉亥（自刑） |

判读口径：**合主顺、冲主动与变、害主暗损、刑主纠缠**。冲不必然是坏——两地分居、出差型职业反而化解冲。

### 4.3 夫妻星（`pub`，《渊海子平》）

- 男命：**正财为妻、偏财为异性缘**；财星被比劫夺 → 竞争多；财星入墓 → 晚婚倾向。
- 女命：**正官为夫、七杀为异性缘**；官星混杂 → 选择困难；官星被伤官克 → 与伴侣口舌。
- 夫妻宫：**日支**。日支被冲、被合、坐忌神 → 关系议题具体化。

### 4.4 紫微夫妻宫主星速查（`school`，《紫微斗数全书》体系，各派解读有差异）

| 主星 | 关系模式关键词 | 常见议题 |
|---|---|---|
| 紫微 | 要求被尊重、伴侣强势或有地位 | 主导权 |
| 天府 | 稳定、重物质安全感 | 财务共识 |
| 太阳 | 付出型、伴侣外向 | 一方过度付出 |
| 太阴 | 细腻、情绪化、重陪伴 | 情绪照顾 |
| 武曲 | 务实、寡言、重实际 | 情感表达不足 |
| 天同 | 温和、依赖、享乐 | 逃避冲突 |
| 廉贞 | 强烈、爱憎分明 | 占有与猜疑 |
| 贪狼 | 多欲、社交广、桃花重 | 边界感 |
| 巨门 | 口舌、猜疑、需沟通 | 沟通方式 |
| 天机 | 变动、思虑多 | 稳定性 |
| 破军 | 破旧立新、聚少离多 | 折腾与重建 |
| 七杀 | 果断、强势、独立 | 互不退让 |
| 天相 | 温和、重体面、易受环境影响 | 立场摇摆 |

辅星修正：左辅右弼 → 有助力也可能有第三人议题；文昌文曲 → 情调与多情；擎羊陀罗 → 摩擦与拖延；
火星铃星 → 激烈争执；地空地劫 → 精神化或空转；化忌 → 执念、旧账反复。

### 4.5 红鸾 / 天喜（`pub`，年支起）

红鸾：子→卯、丑→寅、寅→丑、卯→子、辰→亥、巳→戌、午→酉、未→申、申→未、酉→午、戌→巳、亥→辰。
天喜：红鸾的对冲位（＋6 支）。

### 4.6 咸池桃花（`pub`，《三命通会》年支三合起）

申子辰 → 酉；寅午戌 → 卯；巳酉丑 → 午；亥卯未 → 子。

> 注：桃花主吸引力与被追求，**不主出轨**。把它当「此人容易有异性缘」即可。

## 5 · 解读框架

顺序固定：**盘面事实 → 关系结构 → 摩擦点 → 时间窗口 → 建议**。

### 好输出

> 你日支亥、他日支申：申亥相害，不是冲，属于「相处时容易在细节上互相消耗」——
> 典型表现是一方觉得对方不领情、另一方觉得被挑剔（据《三命通会》地支关系，pub）。
> 你们日干丙火与壬水，丙壬相冲而非五合，说明初见不一定是强吸引，更可能是被现实条件推到一处。
> 紫微两人夫妻宫一坐天同、一坐七杀：一个想息事宁人，一个要立刻解决，冲突时节奏完全相反。
> 两派都指向「沟通节奏」而非「谁克谁」。
> 时间窗口：2027 丁未年，你的红鸾在戌、流年未支与你日支亥成半合，感情议题会被推上台面（流年层，非必婚）。
> 建议：把「谁先低头」换成「先定沟通规则」——冲突时谁都可以喊暂停，24 小时内必须复盘一次。

### 坏输出

> 「你们生肖相冲，八字不合，结婚必有灾。女方命里带煞，需要化解。」
> —— 用民俗层（生肖）当主判据、恐吓式断语、卖化解，三宗罪。

## 6 · 误判清单

| 误判 | 为什么错 | 拦截 |
|---|---|---|
| 拿生肖六冲判「不能结婚」 | 生肖只看年支一个字，占八字八分之一的信息量 | 生肖只作民俗层，标 `undated`，默认不说 |
| 说「你克夫/克妻」 | 无出处、恐吓式、把结构问题人格化 | 改成结构描述（夫妻宫冲、官星受克）+ 可改善点 |
| 只排一方就断合不合 | 合婚必须两盘 | 缺一方 → 降级为「你的盘 + 相处模式」 |
| 把桃花当出轨证据 | 桃花主吸引力 | 明文写「不主出轨」；问出轨 → 转现实沟通 |
| 合婚结论当分手依据 | 替用户做决定 | 只给摩擦点与改善路径，决定交还用户 |
| 生成签诗/签号 | 伪造文本 | 只解读用户提供的原文；不代抽 |
| 同性伴侣硬套「男财女官」 | 规则不适用 | 改用日支关系 + 用神互补 + 夫妻宫 |
| 婚期承诺「必成」 | 择日只避凶 | 写「窗口」不写「保证」 |
