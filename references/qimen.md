# 奇门遁甲（时家）方法论

> 定位：以 `scripts/qimen.py` 的输出为唯一事实源。本文件讲「定时 → 定局 → 布盘 → 取用神 → 判断 → 表达」。
> 历法口径见 `references/calendar.md`；多派对照见 `references/synthesis.md`；边界见 `references/safety-ethics.md`。
> 引用状态用契约 §8 词表：`verified` / `pub` / `school` / `undated`。

---

## 1 · 何时用

**触发**：奇门、奇门遁甲、时家奇门、起局、看盘择时、方位选择、问事、寻物找人、谈判时机、见客户时间、出行方位、签约时点。

**适用**：某事「此刻」的态势（主客关系、阻力点、可用资源）；择时（某日哪几个时辰适合启动/谈判/交付）；方位（配合具体地点与交通现实）；失物/寻人的范围与方向（只给范围，不给「必在」）。

**不适用 / 必须转向**：生死病灾断言、疾病诊断 → 拒绝（`references/safety-ethics.md`）；投资标的、诉讼胜负、赌博 → 不给决定；无任何时间点的泛问 → 先问清「什么事、大概什么时候、你人在哪」；缺时辰 → 时家奇门**无法起局**（§2），不许改用日家/月家而不声明。

---

## 2 · 需要什么输入

| 字段 | 必填 | 说明 | 缺失/异常 → `warning.code` |
|---|---|---|---|
| `--solar YYYY-MM-DD` | **必填** | 定节气、日干支 | 缺 → 报错 exit 2 |
| `--hour HH:MM` | **必填** | 时干支决定旬首、值符、值使 | 缺 → `BAD_INPUT` 报错 exit 2，不给半盘（与 bazi/ziwei 的降级不同） |
| `--ask 事由` | 建议 | 只决定用神取法（§5.1），不参与排盘 | 缺 → 可起局，但只做结构分析，不落「此事成败」 |
| `--pan 转盘\|飞盘` | 可选 | 默认转盘；输出 `result.pan` | 飞盘 → `SCHOOL_VARIANT`（`pan:fei`） |
| `--ju N` | 可选 | 覆盖自动定局（1–9） | 给了 → `JU_OVERRIDE`，并写清覆盖了自动算的哪一局 |
| `--longitude` | 可选 | 真太阳时（与 `bazi.py` 同口径） | 缺 → 北京时间 + `LONGITUDE_ESTIMATED` |

**降级矩阵**：缺时刻 → 无盘，什么都不说；缺事由 → 只做盘面结构描述，不判成败；缺经度 → 按北京时间起局，不谈真太阳时差异；`--ju` 覆盖 → 只按用户局数布盘，不混谈自动定局。

## 3 · 判定流程

1. **定时 → 时干支** — 调 `python3 scripts/qimen.py --solar 2026-11-18 --hour 14:30 --ask "签约时机" --json`；查 `references/calendar.md` 干支/真太阳时；产出 `result.time`（日干支、时干支、时支）。23:00–23:59 必须确认换日口径（同 `bazi.md` §4.15）。
2. **定节气与元** — 读 `result.jieqi`（节气名 + 交节时刻）、`result.yuan`；查 §4.4 三元定局表、§4.5 符头定元表。交节当天必须以**精确交节时刻**判，不许按日期判（差一元 → 局数错）。
3. **定局数与阴阳遁** — 读 `result.ju.{dun,number}`；查 §4.4（冬至→芒种阳遁、夏至→大雪阴遁）。用户给了 `--ju` 时，输出必须并列「自动 X / 用户 Y」。
4. **布地盘三奇六仪** — 查 §4.3 布序 + §4.2 九宫数序；阳遁从局数宫**顺**布、阴遁**逆**布九宫。顺序错一位则全盘错。
5. **定值符值使** — 读 `result.zhifu_star`、`result.zhishi_gate`；查 §4.10（旬首→六仪→落宫→该宫原始九星/八门）。值符取「旬首所临宫的九星」，**不是**时干宫的星。
6. **布天盘、八门、八神** — 读 `result.palaces[9][]`（`gong,direction,earth_stem,sky_stem,star,gate,deity`）；查 §4.6/4.7/4.8/4.9。转盘中五**无门无星**（天禽寄坤二）；若中五有门星即为飞盘口径，须按飞盘解读。
7. **取用神** — 查 §5.1；产出主用神 1–2 个 + 落宫 + 宫的门/星/神/天盘干。一事一占；一次问三件事只答一件，其余另起局。
8. **定吉凶** — 查 §4.11 格局、§4.12 门宫生克；产出「有利/不利」各 1–3 条，逐条挂表。禁止「大凶/必败」。
9. **交叉验证与输出** — 调 `references/synthesis.md`；与八字/紫微的时间判断同向/分歧并列。

**规则表自检**：§4.4/§4.5 与 §4.3 已用独立实现复算 40 个随机时刻（2026-01 至 2027-12，覆盖 23:00 夜子时），节气、日/时干支、三元、阴阳遁、局数、九宫地盘、值符星、值使门、值使落宫 **40/40 全一致**；唯一补充是「时干落中五 → 值符寄坤二」，已写入 §4.9。

### 4.9 中五宫与寄宫（`school`）

- **转盘**：中五不布门、不布星；天禽随天芮寄**坤二**；地盘干仍占中五。
- **飞盘**：九星、八门、八神按宫序飞泊，**中五有星有门有神**。
- 两种寄宫情形，均发 `CENTER_JIGONG`：① 旬首之仪落中五 → 值符取天禽、值使寄坤二死门；② 时干地盘落中五 → 值符临坤二宫（实跑 2026-06-22 23:30 即此例：时干壬落中五，值符天禽落坤二）。

### 4.10 值符值使规则（`pub`）

1. 时干支定旬（甲子/甲戌/甲申/甲午/甲辰/甲寅）。
2. 旬首对应六仪：甲子戊、甲戌己、甲申庚、甲午辛、甲辰壬、甲寅癸。
3. 该六仪在**地盘**所落之宫 = 旬首宫。
4. **值符** = 旬首宫的原始九星；**值使** = 旬首宫的原始八门。
5. 天盘：值符星转到「时干所落之地盘宫」上（时干为甲则用旬首所遁之仪；该宫为中五则寄坤二），其余八星依原序环转（转盘）；天盘干随星走（各星带本宫地盘之干）。
6. 值使落宫：沿**八宫环**（坎一 → 艮八 → 震三 → 巽四 → 离九 → 坤二 → 兑七 → 乾六）从旬首宫起，阳遁顺行、阴遁逆行，步数 =（时支序 − 旬首支序）mod 12；**中五不数**（八门不入中；另一派走含中宫的九宫，会差一到两宫，`SCHOOL_VARIANT:zhishi=ring8`）。
7. 八神：从值符落宫（时干地盘宫）起，沿同一八宫环按「值符 → 螣蛇 → 太阴 → 六合 → 白虎 → 玄武 → 九地 → 九天」阳顺阴逆布。
《烟波钓叟歌》原文（`verified`）：「值符常遣加時干，值使順逆遁宮去。」——即第 5 条（值符加时干）与第 6 条（值使顺逆）的出处。

### 4.12 门宫生克（`school`）

门克宫 = **门迫**（阻力加重）；宫克门 = **门制**（门力被压，需外部推动）；宫生门/门生宫 = 顺；门宫同气 = 旺。

### 4.13 流派分歧：本项目口径

## 5 · 解读框架

四段固定：**盘面事实 → 取用神 → 格局判断 → 概率化表达 + 可行动建议**。

### 5.1 用神取法（`school`）

| 问什么 | 用神 |
|---|---|
| 求测人自身 | 日干（落宫即「我」的处境） |
| 所测之事 | 时干（事体）；日干宫与时干宫的生克 =「我与事」 |
| 事业/公司/求职 | 开门、值符、（年干/太岁为辅） |
| 求财/经营 | 生门、戊（资本）、日干 |
| 婚姻/合作 | 六合；乙奇（女方）、庚（男方，另派用丙丁） |
| 官司/竞争 | 白虎、开门、庚（对手） |
| 疾病/隐患 | 天芮、死门、白虎 |
| 失物/寻人 | 用神类象宫 + 玄武（暗处）/九天（远处） |
| 出行/搬迁 | 九天、开门、所去方位宫 |

### 5.2 判断顺序

**事实**（起局时刻、节气、元、局数、遁、值符值使）→ **用神**（按 §5.1 取 1–2 个，写出落宫与门/星/神/天盘干）→ **判断**（得吉门/吉星/吉神/三奇、门宫生克、格局，逐条列有利与不利）→ **概率化**（只写趋势与条件）→ **建议**（时间窗、方位、动作，并声明「盘只给倾向，最终取决于人」）。

> 事实：2026-11-18 14:30（未时）起局，立冬后 10.86 天，阴遁六局上元；值符天冲落兑七宫，值使伤门落艮八宫；旬首甲午（辛），旬空辰巳。
> 用神：日干丙落艮八宫（天心 + 伤门 + 玄武）；时干乙落兑七宫（天冲 + 死门 + 值符）。
> 判断：日干宫伤门（木）克艮八（土）＝门迫，我方有推进力但摩擦大、易硬碰（§4.12）；时干宫得值符（有背书）+ 天冲（快），死门主收尾旧局，事体偏「结旧账」而非「开新局」（§4.11）；艮土生兑金＝我生事，投入在前、回报在后（§5.2）。
> 概率：若目标是收尾/结案/关账，一周内推进概率较高；若目标是开新合作，未清旧账前反复概率高。
> 建议：① 本周先处理存量合同与旧事项；② 约见选巳时（09–11）或午时，方位取离九（开门 + 太阴）；③ 带齐历史文件，别让对方用旧账拖节奏。

**坏输出（禁止）**：
> 「时干落死门，此事必败，你若强行签约必破财三年。」

问题：① 单宫单门定生死；② 无门宫生克、无格局、无主客关系；③ 恐吓 + 时间跨度乱给；④ 把「死门」当字面死亡。

## 6 · 误判清单

| # | 误判 | 后果 | 拦截办法 |
|---|---|---|---|
| 1 | 用日家/月家/年家局数起时家盘 | 局数全错，九宫全错 | 只允许时家口径；局数必须来自 `result.ju` |
| 2 | 交节日按「日期」判节气 | 差一元 → 局数差 1–2 | 用精确交节时刻（§4.5）；交节日查 `jieqi` |
| 3 | 拆补法与置闰法混用 | 局数不一致却互相引用 | 整盘只许一种（本项目拆补），见 `SCHOOL_VARIANT` |
| 4 | 值符取「时干宫的星」 | 值符、值使、天盘全偏 | 按 §4.10 从旬首宫取，与 `result.zhifu_star` 比对 |
| 5 | 转盘却让中五有门有星 | 宫位挤错 | 转盘中五只放地盘干，天禽寄坤二（§4.9） |
| 6 | 飞盘结果用转盘规则解 | 星门位置解读错误 | 先读 `result.pan`，飞盘按飞泊逻辑解读 |
| 7 | 把八门吉凶当绝对 | 「死门=必死」类结论 | 凶门需门迫/星凶/神凶叠加才算重（§4.12） |
| 8 | 一局多问 | 用神混乱，结论互相矛盾 | 一事一占（§3 步骤 7） |
| 9 | 不看主客（日干与时干生克） | 只描述环境，无「我 vs 事」 | 每条结论写明日干宫与时干宫生克方向 |
| 10 | 用奇门给医疗/法律/投资决定 | 越界 | 触发 `references/safety-ethics.md`，改为「只谈时机与沟通方式」 |
| 11 | `--ju` 覆盖后仍称「自动定局为 X」 | 口径混淆 | 输出并列「自动 X / 用户 Y」并留 `JU_OVERRIDE` |
