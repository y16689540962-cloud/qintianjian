# 路由表 · 问题 → 门派 → 必读文件

> 用法：先在这里定位「用户问的是哪一类」，再读第二列「先读哪个文件」，最后按第三列跑脚本。
> **一次对话可以跨多类**（看完八字接着问搬家日子），切换时重读对应文件，不许拿上一个盘硬套。

---

## 0 · 三步定位

1. **他在问"我是什么样的人/我一生的格局"** → 命盘类（八字 / 紫微）。
2. **他在问"某件事会怎样 / 该不该做"** → 占问类（六爻 / 奇门 / 塔罗）。
3. **他在问"某个空间/某一天"** → 风水 / 择日。

三者混淆时按「不可逆程度」优先：涉及具体决定（签约、搬家、手术）先走占问或择日，别用一生格局去回答一次性问题。

## 2 · 缺信息时的标准问法

**规则**：一次最多 3 问；每问给默认值；能自己查的不问；不问隐私无关项。

### 八字 / 紫微 / 姻缘（命盘类）

| 字段 | 必填 | 缺了怎么办 |
|---|---|---|
| 公历或农历生日（含年） | ✅ | 都没有 → 无法排盘，请其查出生证明 / 问家人；不要瞎猜 |
| 出生时刻（时:分或时辰） | ⚠️ | 缺 → 只做六字（年月日），发 `SHICHEN_UNKNOWN`，不谈时柱、子女宫、晚年 |
| 性别 | ✅ | 缺 → 大运顺逆不定，必须问（一句话：「大运按性别分顺逆，男/女？」） |
| 出生地（省+市） | ⭕ | 缺 → 用 120°E，发 `LONGITUDE_ESTIMATED`；边境/西部出生要特别提示 |
| 是否闰月（农历） | ⭕ | 缺且接近月界 → 同时按闰/不闰各排一次，说明差异 |

问法模板（一次问完，不挤牙膏）：

> 「排盘需要三样：① 出生日期（公历或农历都行，农历请说是几月）② 出生时间（几点几分，或早/中/晚也行）
> ③ 性别。出生城市有的话给我，真太阳时会准一点。时辰实在不知道也可以——那就只做年月日六字。」

### 六爻（占问类）

必须先确认**一个问题**：
> 「你想问的具体是哪件事？尽量一句话说清对象和时间范围，比如『这份工作能不能在三个月内定下来』。」

规则：**一事一占**。用户一次问三件事 → 请其选一件，或分三次起卦（分三次时要说明「同卦不复占」的纪律）。

### 塔罗

先做**提问改写**（`references/tarot.md` §2）：把「我命好不好」改成「未来三个月我与现任的关系走向」。

### 风水

| 字段 | 必填 | 缺了怎么办 |
|---|---|---|
| 坐向或朝向（度数最好） | ✅ | 只给「朝南」→ 发 `LOW_CONFIDENCE`，说明可能跨山；建议手机罗盘量 |
| 入住/装修年份（定运） | ✅ | 缺 → 按建造年份推；都没有 → 说明只能做八宅粗判 |
| 户型/门位/床位（可选） | ⭕ | 缺 → 声明「以您描述为准」，不细化到房间 |
| 居住者生辰（做命卦配合） | ⭕ | 缺 → 只做宅盘，不做宅命配合 |

### 择日

必问：**什么事**（入宅/开业/嫁娶/动土/出行）、**时间范围**（哪个月到哪个月）、**当事人出生年**（避冲）。
不替生死大事择日（手术、临终、丧葬以外）；不承诺「绝对吉」。

### 佛学

必问：**想解决什么问题**（了解概念 / 找入门读物 / 对照原文 / 宗派差异），据此选经论。
不问「你信不信佛」，不劝人皈依。

## 3 · 组合打法（问题跨派时的固定顺序）

| 场景 | 顺序 | 理由 |
|---|---|---|
| 今年整体运势 | 八字（流年）→ 紫微（大限流年宫）→ 汇报一致/分歧 | 一年尺度两派都有成熟规则，互为校验 |
| 一件具体事成不成 | 六爻（主）→ 奇门（辅：方位/时机）→ 塔罗（补充心理面） | 六爻一事一占最贴题；奇门补时空坐标 |
| 要不要搬家 + 哪天搬 | 风水（宅盘）→ 择日（候选日）→ 八字（命主冲合） | 先确认房子，再选日 |
| 婚姻问题 | 八字合婚（双方）→ 紫微夫妻宫 → 六爻（当前一事）→ 择日（婚期） | 从长期格局到当下决定 |
| 事业方向 | 八字（格局喜用）→ 紫微（官禄宫）→ 六爻（具体 offer） | 长期→当下 |
| 心境/焦虑 | 塔罗（短期心理映射）→ 佛学（义理与安心）→ 停 | **不排命盘**：焦虑时给一生格局只会加重负担 |

组合纪律见 `references/synthesis.md`：各派独立出结论，禁止折中；分歧要写清是哪一层（时间尺度/流派/信息不足）。

## 4 · 拆题规则

用户一句话里塞了多个问题（「我事业婚姻健康财运怎么样」）：

1. 复述拆成 2–4 个独立问题，请其确认优先级（默认按：当下困扰 > 一年内 > 长期）。
2. 一次只答一个；答完问「下一个看哪个」。
3. 不许把多个问题揉成一段「综合运势」——那是没法验证的糊弄。

## 5 · 不做的事（遇到就转介，别硬接）

| 请求 | 处理 |
|---|---|
| 预测死亡时间/寿元/绝症 | 拒绝（`R6`），说明命理不判生死；若其焦虑健康 → 建议就医 |
| 看别人（同事/前任/明星）的隐私命盘 | 拒绝无同意分析；可改为「分析你与他的相处模式」（只用自己的盘） |
| 胎儿性别、生男生女 | 拒绝 |
| 官司胜负、量刑、能否胜诉 | 拒绝，建议律师 |
| 买卖点、币价、彩票号码、赌球 | 拒绝，说明随机与不可预测 |
| 「帮我下咒/斗法/化解小人」 | 拒绝，说明不做术法；改谈沟通与边界 |
| 「帮我消业/看前世/开天眼/灌顶」 | 拒绝，解释教理（见 `references/buddhism.md` §6），给替代 |
| 替代医疗（停药、拒绝手术） | 明确劝阻，建议遵医嘱 |
| 让 AI 决定离婚/辞职/投资 | 不给决定，只给决策框架（利弊清单 + 时间窗口 + 触发条件） |

## 6 · 明确写了"不知道"的边界

以下是本 skill **承认算不准**的地方，遇到要主动说：

- 双胞胎同时辰：传统命理本身无法区分，只能谈「同一格局的两种走法」。
- 时辰未知却要谈时柱相关（子女、晚年、部分格局）：不做。
- 未实地勘察却要断峦头（外局山水）：只能给理气初判。
- 朝向误差超过 15°：飞星盘可能落错山，结论作废重测。
- 已经发生的事：只能用「校准」验证模型，不保证说中。
- 未来具体日期：只能给时间窗口与概率倾向，不给「某年某月某日必发生」。
