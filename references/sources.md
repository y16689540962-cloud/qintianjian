# 引文出处总表与核对状态

> 规则只有一条：**没有登记在这里的说法，不许说成"出自《某书》"。**
> 各模块文档末尾的「出处与核对状态」节是本文的分册；本文是总索引与口径仲裁。

---

## 1 · 四级状态（全库唯一标准）

| 状态 | 标记 | 定义 | 允许的说法 |
|---|---|---|---|
| 原文核对 | `verified` | 逐字核对过某个**可复现的版本**，并在下表注明版本来源 | 「《X》云：『……』」 |
| 通行出处 | `pub` | 公认出自该书/该体系，措辞可能与本项目表述不同 | 「据《X》……」 |
| 流派口径 | `school` | 某派或后世通说，非经典原文；或各派做法不同 | 「某派以……为法」「通行做法是……」 |
| 无确证 | `undated` | 流行口诀或民俗，查无确证作者/出处 | 「旧诀云……」「民俗上认为……」 |

**一条实测教训（值得记住）**：Lead 第一次检索 V4 时判「查无此句」，原因是维基文库原文用异体字 `説`（U+8AAC），

## 3 · 常见伪造引文（黑名单，出现即返工）

| 伪引文 | 问题 |
|---|---|
| 「《滴天髓》云：男命财多则桃花旺」 | 查无此句，系现代网文自造 |
| 「《三命通会》说：女命官杀混杂必二婚」 | 原书论女命更复杂，此句为简化断章 |
| 「《易经》第 64 卦是乾卦」 | 卦序错误（乾为第 1 卦） |
| 「《紫微斗数全书》云：紫微入命必贵」 | 原书无此绝对判断 |
| 「《葬书》云：门前有树必出贵人」 | 无出处，属民间说法 |
| 「佛说：前世五百次回眸……」 | 非佛经，属现代文艺句 |
| 「《推背图》预言 2027 年……」 | 版本混乱、谶纬附会，不引用 |
| 「科学证明风水有能量场」 | 伪科学表述，禁止 |

**处理**：遇到用户引用此类句子，说「这句查不到确切出处，可能是网络流传的改写」，然后给有出处的替代说法。

## 4 · 引用格式

```
《书名》云：「引文……」（状态，卷/篇）
```
例：
```
《渊海子平·论财官》云：「男以财为妻，女以官为夫。」（pub）
```

- 不确定篇名时省略篇名，但不许编篇名。
- 同一段连续引同一书，第二次起可简写「同上」。
- 引现代研究或注本时，写成「据某某《书名》（出版社，年份）」，状态标 `school`。

## 5 · 维护规则

1. 新增说法 → 先查本表；不在表里 → 先按 `undated` 说，再补登记。
2. 模块文档新增引文 → 同步在本表 2.x 补一行（或至少在其分册里登记）。
3. 任何 `verified` 条目必须四要素齐全（书名/篇卷/版本/核对人），否则删除该状态。
4. 发现本文与模块文档冲突 → 以本文为准，同时改模块文档。
