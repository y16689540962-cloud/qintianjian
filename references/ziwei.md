# 紫微斗数方法论

> 定位：以 `scripts/ziwei.py` 的输出为唯一事实源。本文件只讲「怎么排、查哪张表、怎么判、怎么说」。
> 历法口径见 `references/calendar.md`，跨派对照见 `references/synthesis.md`，输出边界见 `references/safety-ethics.md`。
> 引用状态用契约 §8 词表：`verified` / `pub` / `school` / `undated`。

---

## 1 · 何时用

**触发**：紫微斗数、紫微、斗数、命盘、十二宫、命宫身宫、主星、四化、大限、流年、看夫妻宫/财帛宫/官禄宫、紫微合婚。

**适用问题**：
- 十二宫结构（哪一宫星曜最密/最空、四化落在哪一宫 → 人生重心与压力点）
- 性格与行事风格（命宫三方四正的星曜组合）
- 关系与事业的具体场景（夫妻宫、官禄宫、财帛宫、迁移宫）
- 时间结构（大限 10 年段落 + 流年触发点）

**不适用 / 必须转向**：
- 医疗诊断、法律结论、投资标的 → 拒绝（`references/safety-ethics.md`）
- 「几岁会死」「能不能活过 X 岁」→ 禁止
- 只有年月日没有时辰 → 时支决定命宫，**无时辰无法排盘**，只能降级（§2），不许猜
- 把紫微当八字用「补五行」→ 斗数不论五行缺补，转 `references/bazi.md`

## 2 · 需要什么输入

| 字段 | 必填 | 说明 | 缺失/异常 → 降级 + `warning.code` |
|---|---|---|---|
| 公历 `--solar` / 农历 `--lunar` | 二选一 | 内部换算农历（命宫按农历月与日） | `--solar` 落到闰月 → `LEAP_MONTH`；`--lunar` 漏 `--leap` 时按平月排且**不发警告**（实跑确认）→ 用 `--lunar` 前必须确认该年有无闰月 |
| 出生时刻 `--hour` 或 `--shichen` | **必填（定命宫）** | 时支定命宫/身宫，缺了宫位全不成立 | 缺 → 实跑：`ok:true` 只输出农历 + 生年四化表（无命宫/五行局/星曜）+ `SHICHEN_UNKNOWN`，exit 0；此时禁谈任何宫位结论 |
| 性别 `--sex 男\|女` | **必填** | 决定大限顺逆（另一些星曜的性别取法本项目不分） | 缺 → `BAD_INPUT` 报错 exit 2；不许默认男 |
| 经度 `--longitude` | 可选 | 与八字同口径的真太阳时 | 缺 → 用北京时间 + `LONGITUDE_ESTIMATED` |
| 流年 `--liunian N` | 可选 | 只看某年流年盘 | 缺 → 只排本命 + 大限 |
| 闰月标记 `--leap` | 条件必填 | 闰月生人必须先定归属（§4.12） | 未标 → `LEAP_MONTH`，并按本项目口径默认处理 |

另外两类信息性 warning（不是缺信息，但必须复述）：`SCHOOL_VARIANT`（生年四化在庚/戊/壬干的派别分歧，实跑 detail：`year_divide=lunar_new_year`（年干支以农历正月初一为界）、`sihua=ren_zuofu_deviation`（壬干四化偏离原文）、`sihua=geng_wu`、`leap_month=split_15`；另 `result.school_notes[]` 逐条列出全部口径）、`LONGITUDE_ESTIMATED`。

**降级矩阵**：

| 缺失 | 还能说 | 必须禁说 |
|---|---|---|
| 时辰未知 | 农历、生年四化表 | 任何命宫/主星/五行局/宫位结论 |
| 经度未知 | 北京时间排盘 | 真太阳时下命宫可能移位的具体结论 |
| 闰月归属不明 | 按 §4.12 默认口径排，并标注 | 把「闰月前后半月」的差异当定论 |
| 生日存疑 | 标注不确定，并列两盘差异 | 精断 |

## 3 · 判定流程

1. **定农历与时支** — 调 `python3 scripts/ziwei.py --solar 1990-05-15 --hour 12:00 --sex 男 --json`；查 `references/calendar.md` 农历/闰月/真太阳时口径；产出 `result.lunar`（农历 + leap）、`result.yin_yang`、`warnings[]`。`lunar.leap=true` 必须走 §4.12 口径，不许当平月。
2. **定命宫与身宫** — 读 `result.ming_gong.{branch,stem,ganzhi}`、`result.shen_gong.{branch,palace_name}`；查 §4.2 公式；产出命宫/身宫地支（身宫常落命/夫妻/财帛/迁移/官禄/福德）。手算复核一次，不一致以脚本为准。
3. **定五行局** — 读 `result.wuxing_ju`；查 §4.3 五虎遁 → §4.4 纳音五行局；产出局数（决定紫微定位与大限起运虚岁）。命宫天干必须由年干五虎遁推出，不许拿年干当命宫干。
4. **安十四主星** — 读 `result.palaces[12][].stars[]`（`name,type,brightness,sihua`）；查 §4.5 紫微定位 → §4.6 紫微系/天府系；产出十二宫主星 + 庙旺等级。十四主星必须全落且不重复，缺一或多一即脚本异常，停下报告。
5. **安辅星、煞星与四化** — 读 `stars[].sihua`、`result.sihua_year.{school,variant_note}`、`result.school_notes[]`；查 §4.7 庙旺、§4.8 四化（注明派别）、§4.9 辅煞；产出四化落宫（禄/权/科/忌）与六吉六煞分布。四化只许一栏，换派必须整盘重排。
6. **排大限** — 读 `result.daxian[]`（起止岁数 + 宫位）；查 §4.10；产出每限 10 年序列 + 当前大限。起运虚岁 = 局数，顺逆按「阳男阴女顺、阴男阳女逆」，与 `daxian[0]` 对齐。
7. **排流年（可选）** — `--liunian N` 读 `result.liunian`；查 §4.11；产出流年命宫落宫 + 与生年四化的叠加。流年只作触发点，不得推翻本命结论。
8. **交叉验证** — 调 `references/synthesis.md`；与八字（`references/bazi.md`）同向/分歧并列，不折中。

**规则表自检**：§4.2/§4.4/§4.5/§4.6/§4.8 已用独立实现复算 30 个随机盘（1970–2024，含 23:00 夜子时、闰月 2009 闰五月十八等边界），命宫、身宫、五行局、十四主星落宫、生年四化、大限顺逆 **30/30 全一致**。另确认两处口径：① 年干支以**农历正月初一**为界（2026-02-10 判乙巳，非立春后的丙午）；② 闰月十六以后按次月（`month_index_used=6`）。

## 4 · 规则表

### 4.1 十二宫次序（`pub`）

从命宫起**逆时针**（地支序递减）排：
命宫 → 兄弟 → 夫妻 → 子女 → 财帛 → 疾厄 → 迁移 → 交友（奴仆）→ 官禄（事业）→ 田宅 → 福德 → 父母。

三方四正 = 本宫 + 对宫（迁移）+ 三合两宫（财帛、官禄；即本宫 ±4、±8 宫）。

### 4.2 命宫 / 身宫公式（`pub`）

- **命宫**：寅宫起正月，顺数至生月；从该宫起子时，**逆**数至生时，所落之宫即命宫。
- **身宫**：寅宫起正月，顺数至生月；从该宫起子时，**顺**数至生时，所落之宫即身宫。
- 公式：命宫 = (寅 + (月−1) − 时支序) mod 12；身宫 = (寅 + (月−1) + 时支序) mod 12（子=0）。
据《紫微斗數全書》卷二·安身命例（`pub`）：命从寅上起正月，顺数至生月，再自生月起子时逆数至生时安命、顺数至生时安身。**未标 `verified`**：维基文库本（revid=1963110）该段为简体转录，繁体引文与之不逐字一致，按 §7 门槛降为 `pub`。

### 4.5 紫微定位规则（`pub`，《全书》定紫微诀）

以生日 d 与局数 j 定紫微宫位（子=0 … 寅=2 …）：
1. 商 q = ⌈d / j⌉（最小正整数使 q×j ≥ d）；借数 r = q×j − d。
2. 从**寅宫**起数到第 q 宫：pos = 寅 + (q−1)。
3. 借数 r 为**奇数 → 从 pos 逆退 r 宫**；r 为**偶数 → 顺进 r 宫**（含 r=0 不动）。
4. 结果对 12 取模。

据《紫微斗數全書》卷二安星诀（`pub`）：水二局「初一起丑、初二寅」，与本条规则的输出一致。同样因页面为简体转录，**不标 `verified`**。

校验例（水二局 j=2）：初一 q=1,r=1（奇，逆退 1）→ **丑**；初二 r=0 → **寅**；初三 q=2,r=1 → 卯退 1 = **寅**；初四 r=0 → **卯**；初十 q=5,r=0 → **午**。木三局 j=3 初一 q=1,r=2（偶，顺进 2）→ **辰**。土五局 j=5、日 21：q=5,r=4（偶）→ 寅+4=午，再顺进 4 → **戌**（与 §3.1 实跑盘的「紫微(得)在戌」一致）。

### 4.10 大限起法与顺逆（`pub`）

- 起运虚岁 = 五行局数（水二局 2 岁起）。
- 顺逆：**阳男阴女顺行**（命宫→兄弟→夫妻…方向），**阴男阳女逆行**；阴阳以生年干（甲丙戊庚壬为阳）与性别定。
- 每限 10 年，十二宫各主一限，循环一轮 120 年。

### 4.11 流年与小限（`school`）

- 流年命宫：以流年地支所在宫为流年命宫，逆行布流年十二宫。
- 流年四化：以流年天干按 §4.8 同表再起一组四化，称「流年四化」，只看是否冲照本命四化所落之宫。
- 小限：男命从命宫顺行、女命逆行，一年一宫（本项目以脚本输出为准，未输出则不谈小限）。

## 5 · 解读框架

四段固定顺序：**盘面事实 → 规则判断 → 概率化表达 → 可行动建议**。每段都不许跳。

1. **盘面事实**：命宫/身宫地支、五行局、十四主星落宫、生年四化落宫、当前大限。只念脚本字段。
2. **规则判断**：先看命宫三方四正（§4.1）；再看四化落宫（禄=资源入口、权=主导权、科=名声/文书、忌=卡点）；再看煞星是否入关键宫。每条挂到 §3 步骤或 §4 表。
3. **概率化表达**：用「结构偏向 / 更容易 / 在 X 情境下」；禁止「注定/必定/一定」。四化忌不说「破财」，说「该宫位对应领域容易出现反复投入」。
4. **可行动建议**：2–3 条当下可做的事（补流程、换协作方式、设止损线、延后决策），不给「改运/化解」类话术。

**好输出（节选）**：
> 事实（§3.1 那张盘）：命宫丁亥、天梁（陷），身宫同宫；土五局、阳男顺行，大限 5–14 在命宫；生年四化 太阳禄 + 太阴科落财帛（癸未）、武曲权落疾厄（壬午）、天同忌落迁移（辛巳）。
> 判断：命宫天梁落陷、三方四正为七杀（父母）、天同（迁移）、天机巨门（夫妻）；迁移宫天同化忌 → 外出与异地事重复投入；财帛双星一「得」一「不」→ 收入与名声、文书相关，与重资产无关（§4.1 + §4.7 + §4.8）。
> 概率：在长期驻外或高变动环境更易内耗；「有制度背书的专业身份」比「自己开路」更顺。
> 建议：① 岗位优先选需要讲清道理、有制度支撑的位置；② 频繁换城市/长期出差要预留恢复期；③ 收入不要押在单一来源，先攒可迁移的专业凭证。

**坏输出（禁止）**：
> 「你夫妻宫巨门化忌，必离婚，二婚才好。」

问题：① 化忌=沟通摩擦，不是离婚判决；② 无表可追；③ 恐吓式断语；④ 无视三方四正与大限。
